DeliveryTracker support

Last updated 15 October 2026

DeliveryTracker records equipment deliveries to churches: equipment, contacts, photographs, installation and training. It runs on Android 8.0 and later.

Getting access

Check the apps page for the current release and Android APK download availability.

Ask your mission administrator for a personal API key and access to the mission section. The first sign-in needs an internet connection. Self-service key requests are not currently available.

Working offline

After successful online verification, the same user can reopen the app offline. Changes and photos save on the phone first. Check the upload queue for pending changes or errors; uploads resume when connectivity and account access are available. Keep the app installed until all work is synced.

Moving to another phone or replacing a test build

Do not uninstall or clear app data while uploads are pending. Sync first and use Settings to export a recovery ZIP. The ZIP contains sensitive field data; store it securely. It is a support recovery format, with no automatic import.

An older test build signed with the Android debug key cannot be updated in place by a release-signed APK. Contact support before replacing it, especially if it contains unsynced records or photos.

Photos after reinstall

Once signed in online, delivery records and photo metadata load from the server. Remote photos appear as icons; the app does not download all original photos automatically. Unsynced photos exist only on their original phone. Archiving an uploaded photo retains its original on the server.

Contact

Contact your mission administrator first. For application support: info@misia.sk. Include your Android version and a description of the problem. Never send your API key.

Podpora v slovenčine: Prístup vyžaduje osobný API kľúč od správcu a prvé online prihlásenie. Potom môžete pracovať aj bez internetu. Pred odinštalovaním synchronizujte všetky čakajúce zmeny a fotografie. Záložný ZIP sa nedá automaticky importovať. Kontakt: info@misia.sk.
